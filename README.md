# 웨스트빌 가구 배치 스튜디오

목동 웨스트빌 100B형의 추정 평면도를 바탕으로 가구와 내부 벽을 배치해 보는 웹 도구입니다.

## 사용 방법

1. 가구의 가로와 세로를 cm로 입력하고 추가합니다.
2. 가구를 끌어 배치하고 필요하면 90도 회전합니다. 가구는 벽에 붙으며 벽과 겹치지 않습니다.
3. 벽 지우기와 복원하기에서 내부 벽을 구간별로 수정합니다.
4. 도면을 90도 회전하거나 이미지로 저장할 수 있습니다.

작업은 각 방문자의 브라우저에 저장됩니다. 배치 파일을 내려받아 다른 기기로 옮길 수도 있습니다. 서버에서 가구 배치를 저장하거나 공유하지 않습니다.

## 실행과 배포

`index.html`을 웹서버에서 열면 동작합니다. GitHub Pages에서는 `main` 브랜치의 루트를 사이트로 설정할 수 있습니다. 설치나 빌드 과정은 필요하지 않습니다.

## 참고 사항

평면도의 치수는 제공된 이미지와 전용면적을 이용해 추정한 값입니다. 시공이나 가구 주문 전 실측이 필요하며, 실제 벽 철거 가능 여부는 전문가와 확인해야 합니다.
